# House Price Prediction using Machine Learning

## Project Overview
This project predicts house prices using machine learning regression algorithms.

## Algorithms Used
- Linear Regression
- Random Forest Regressor
- Gradient Boosting Regressor

## Workflow
1. Data Loading
2. Data Exploration
3. Missing Value Handling
4. Exploratory Data Analysis
5. Feature Encoding
6. Feature Scaling
7. Model Training
8. Model Evaluation
9. Residual Analysis
10. Model Saving

## Evaluation Metrics
- RMSE
- MAE
- R2 Score

## Technologies Used
- Python
- Pandas
- NumPy
- Seaborn
- Matplotlib
- Scikit-learn
- Joblib

## Conclusion
The project successfully predicts house prices using regression models and demonstrates a complete machine learning workflow.
